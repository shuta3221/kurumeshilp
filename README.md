# くるめし 法人専用窓口LP

Cloudflare Pagesで公開するための静的サイト一式です。

## Cloudflare Pagesの設定

- Production branch: `main`
- Framework preset: `None`
- Build command: `exit 0`
- Build output directory: `.`

GitHubリポジトリのルートへ、このフォルダ内のファイルをそのままアップロードしてください。
`main`ブランチへの反映後、Cloudflare Pagesのテストドメイン（`*.pages.dev`）で公開できます。
